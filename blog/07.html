モーションとコンバージョンの関係

ランディングページ（LP）にアニメーションを追加することは、ただ「かっこよく見せる」ためではありません。適切なモーション設計はユーザーの視線を意図した順番で誘導し、情報の優先順位を直感的に伝えます。その結果としてCVR（コンバージョン率）の向上に繋がります。

ただし、過剰なアニメーションはページ速度を低下させ、逆効果になります。「少なく、的確に」が原則です。

ヒーローセクションの入場演出

ページ読み込み直後、ユーザーが最初に目にするヒーローセクションの演出が最も重要です。要素を順番に登場させることで「何を見れば良いか」を明確にします。

// ヒーロー入場アニメーション
const reduced = window.matchMedia('(prefers-reduced-motion: reduce)').matches;

const tl = anime.timeline({ easing: 'easeOutCubic' });

// 1. 背景（最初に）
tl.add({ targets: '.hero-bg', opacity: [0, 1], duration: 500 })
// 2. キャッチコピー（少し上から）
  .add({
    targets: '.hero-headline',
    opacity: [0, 1],
    translateY: reduced ? 0 : [24, 0],
    duration: 500
  }, '-=200')
// 3. サブコピー
  .add({
    targets: '.hero-subtext',
    opacity: [0, 1],
    translateY: reduced ? 0 : [16, 0],
    duration: 400
  }, '-=250')
// 4. CTAボタン（最後・スケールで強調）
  .add({
    targets: '.hero-cta',
    opacity: [0, 1],
    scale: reduced ? 1 : [0.88, 1],
    duration: 350,
    easing: 'easeOutBack'
  }, '-=200');

スクロール連動フェードインの設計

スクロールに応じて順番に登場する要素は「まだ先がある」という期待感を生み、ユーザーをページ下部へ誘導します。ただし以下に注意してください。

  • アニメーション前の要素はopacity:0にする（SEOのためvisibilityは非推奨）
  • スクロールイベントではなくIntersection Observerを使う（パフォーマンス）
  • アニメーション距離は最大30px程度（大きな移動はモーション酔いの原因）
// スクロール連動フェードイン
const io = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (!entry.isIntersecting) return;
    const el = entry.target;
    const reduced = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
    anime({
      targets: el,
      opacity: [0, 1],
      translateY: reduced ? 0 : [20, 0],
      duration: reduced ? 200 : 500,
      easing: 'easeOutCubic'
    });
    io.unobserve(el);
  });
}, { threshold: 0.12 });

document.querySelectorAll('[data-scroll-reveal]').forEach(el => {
  el.style.opacity = '0';
  io.observe(el);
});

CTAボタンのマイクロアニメーション

最終的なコンバージョンポイントとなるCTAボタンには、存在感を示すサブルなアニメーションを付与します。ただし「うるさすぎない」ことが重要です。

// ホバー時の微細なリフト（CSSで実装が最も軽量）
//.cta-btn { transition: transform 0.15s easeOutCubic, box-shadow 0.15s; }
//.cta-btn:hover { transform: translateY(-2px); box-shadow: 0 8px 20px rgba(99,102,241,0.5); }

// 定期的な「注目パルス」（ページ滞在30秒後）
setTimeout(() => {
  anime({
    targets: '.main-cta',
    scale: [1, 1.04, 1],
    duration: 600,
    easing: 'easeOutElastic(1, 0.5)'
  });
}, 30000);

社会的証明（数値・レビュー）のカウントアップ

「10,000+ユーザー」「満足度98%」などの数値をカウントアップ表示する演出は、統計的な指標を印象的に強調し、信頼感を高めます。

// カウントアップアニメーション
function countUp(el, target, duration = 1200) {
  anime({
    targets: { val: 0 },
    val: target,
    duration,
    easing: 'easeOutExpo',
    update: function(anim) {
      el.textContent = Math.round(anim.animations[0].currentValue).toLocaleString();
    }
  });
}

// Intersection Observerで画面内に入ったら起動
const observer = new IntersectionObserver(entries => {
  entries.forEach(entry => {
    if (!entry.isIntersecting) return;
    countUp(entry.target, parseInt(entry.target.dataset.count), 1200);
    observer.unobserve(entry.target);
  });
});

document.querySelectorAll('[data-count]').forEach(el => observer.observe(el));

パフォーマンスと速度の注意点

LPはファーストビューの読み込み速度がCVRに直結します。以下を守りましょう。

  • アニメーション用のJSはdeferまたはasyncで読み込む
  • 大きな画像アニメーションはCSSで処理し、JavaScriptアニメーションはtransform/opacityのみ
  • クリティカルパスCSSにアニメーション前スタイル（opacity:0等）を含める
  • Core Web Vitals（LCP・CLS・INP）への影響を定期的にPageSpeed Insightsで計測する
