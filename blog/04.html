モーション酔いとは

「モーション酔い（motion sickness）」は、視覚的な動きと前庭感覚（バランス感覚）の不一致から生じる不快感です。車酔いと同じメカニズムが、画面上の激しいアニメーションによっても引き起こされます。前庭機能障害（vestibular disorder）を持つ人口は成人の約35%と推計されており、Webサイトのアクセシビリティに深刻な影響を与えます。

軽いケースでは「なんか見てて疲れる」「ちょっと気持ち悪い」程度ですが、重篤なケースでは頭痛・嘔吐感・数時間続く不快感を引き起こすこともあります。

モーション酔いを引き起こすパターン

パターン1：パラレックス効果

スクロールに合わせて背景と前景が異なる速度で動くパラレックス効果は、最も酔いを引き起こしやすいデザインの一つです。視覚的には「奥行き感がかっこいい」ですが、前庭感覚との不一致が強烈です。

パターン2：大きな平行移動

translateX/Yで画面幅に近い大きな距離を移動するアニメーションは危険です。特に水平方向の大移動は前庭感覚を強く刺激します。移動距離は最大でも画面幅の25%以下を目安に。

パターン3：ズーム（大きなscale変化）

0から1など大きなscaleアニメーションは、まるで「ズームイン」されるような強い視覚刺激を与えます。0.9〜1.0などの小さな変化に留めるか、Reduced Motion時はゼロにしましょう。

パターン4：継続的なループアニメーション

ループで回転し続ける要素・揺れ続ける要素は、視野の中で常に動き続けるため蓄積疲労を引き起こします。必要な場合のみ使い、ユーザーが止められる手段（ホバーでpause等）を提供しましょう。

パターン5：フラッシュ・点滅

1秒間に3回以上の点滅は光感受性てんかんを引き起こす可能性があり、WCAG 2.1で明確に禁止されています（Success Criterion 2.3.1）。

prefers-reduced-motionを使った対策

OS設定「視差効果を減らす（iOS/macOS）」「Windowsのアニメーションを無効にする」などをONにするユーザーに対して、安全なアニメーションを提供します。

// anime.jsでのReducedMotion対応パターン
function safeAnime(opts) {
  const reduced = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
  if (!reduced) return anime(opts);

  // 移動アニメーションをゼロ化
  const safeOpts = { ...opts };
  if (safeOpts.translateX) safeOpts.translateX = Array.isArray(safeOpts.translateX) ? [0, 0] : 0;
  if (safeOpts.translateY) safeOpts.translateY = Array.isArray(safeOpts.translateY) ? [0, 0] : 0;
  if (safeOpts.rotate) delete safeOpts.rotate;
  if (safeOpts.scale) safeOpts.scale = Array.isArray(safeOpts.scale) ? [1, 1] : 1;
  safeOpts.duration = Math.min(safeOpts.duration || 400, 200);
  return anime(safeOpts);
}

何は残して、何は消すか

消すべきもの：translateX/Y（大きな移動）、rotate（連続回転）、大きなscale変化、パラレックス、3Dパース

残してよいもの：opacity（フェード）、小さなscale（0.95〜1.0）、背景色変化、アンダーライン等のCSS装飾変化

ユーザーへのコントロール提供

OS設定に依存するだけでなく、サイト内に「アニメーションを停止する」ボタンを設置することも選択肢の一つです。localStorageに保存してリロード後も設定を維持できます。

// アニメーション停止ボタンの実装例
const motionToggle = document.querySelector('#motionToggle');
let motionDisabled = localStorage.getItem('motionDisabled') === 'true';

if (motionDisabled) document.documentElement.classList.add('no-motion');

motionToggle.addEventListener('click', () => {
  motionDisabled = !motionDisabled;
  localStorage.setItem('motionDisabled', motionDisabled);
  document.documentElement.classList.toggle('no-motion', motionDisabled);
});
