なぜアニメーションのアクセシビリティが重要か

Webアクセシビリティとは、すべての人が平等にWebコンテンツを利用できるようにする取り組みです。アニメーションは視覚的な豊かさを加える反面、適切に実装しないと特定のユーザーグループを排除することになります。

WCAG（Web Content Accessibility Guidelines）2.1では、モーションに関する成功基準として主に以下が定められています。

  • SC 2.3.1（レベルA）：3フラッシュ以内の周波数、または閾値以下であること
  • SC 2.3.3（レベルAAA）：ユーザーがインタラクションによって引き起こされるモーションアニメーションを無効にできること
  • SC 2.1.1（レベルA）：すべての機能がキーボードで操作可能であること

prefers-reduced-motion の対応

最低限実装すべきアクセシビリティ対応です。詳細はモーション酔いを防ぐWebデザイン記事も参照してください。

// グローバルに設定
const REDUCED = window.matchMedia('(prefers-reduced-motion: reduce)').matches;

// アニメーション関数を共通化
function pageEnter(el) {
  anime({
    targets: el,
    opacity: [0, 1],
    translateY: REDUCED ? 0 : [20, 0],
    duration: REDUCED ? 150 : 500,
    easing: 'easeOutCubic'
  });
}

スクリーンリーダーとの共存

アニメーションで表示・非表示を切り替える場合、スクリーンリーダーにも状態変化を伝える必要があります。

// aria-live でスクリーンリーダーに変化を通知
const announcer = document.createElement('div');
announcer.setAttribute('aria-live', 'polite');
announcer.setAttribute('aria-atomic', 'true');
announcer.className = 'sr-only'; // 視覚的には非表示
document.body.appendChild(announcer);

// アニメーション完了後にスクリーンリーダーに通知
function openModal(modal) {
  modal.removeAttribute('hidden');
  anime({
    targets: modal,
    opacity: [0, 1],
    scale: [0.9, 1],
    duration: 300,
    complete: () => {
      announcer.textContent = 'ダイアログが開きました';
      modal.querySelector('[autofocus], h2, [tabindex="-1"]')?.focus();
    }
  });
}

フォーカス管理

モーダル・ドロワーなどのアニメーションで、表示完了後に適切な要素にフォーカスを当てることが重要です。

// モーダルを開いたとき：最初のフォーカス可能要素にフォーカス
function openModal(modal, triggerEl) {
  modal.removeAttribute('hidden');
  anime({
    targets: modal,
    opacity: [0, 1],
    scale: [0.85, 1],
    easing: 'easeOutBack',
    duration: 350,
    complete: () => {
      const focusable = modal.querySelector('button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])');
      focusable?.focus();
    }
  });

  // 閉じたとき：開いたボタンにフォーカスを戻す
  modal.addEventListener('close', () => triggerEl.focus(), { once: true });
}

キーボードで制御できるアニメーション（ESCで閉じる等）

// Escキーでモーダルを閉じる
document.addEventListener('keydown', (e) => {
  if (e.key === 'Escape') {
    const openModal = document.querySelector('.modal:not([hidden])');
    if (openModal) closeModal(openModal);
  }
});

アニメーション中のaria-busy

// データロード中のローディング状態をARIAで通知
const container = document.querySelector('#content');
container.setAttribute('aria-busy', 'true');
container.setAttribute('aria-label', 'コンテンツを読み込み中');

// スケルトンUI表示アニメーション...

// 完了後
data = await fetchData();
renderContent(container, data);
container.setAttribute('aria-busy', 'false');
container.removeAttribute('aria-label');

チェックリスト

  • ✅ prefers-reduced-motion 対応（全アニメーション）
  • ✅ 点滅・フラッシュは1秒3回以内（WCAG SC 2.3.1）
  • ✅ モーダル等の表示時にフォーカス管理
  • ✅ Escキーでオーバーレイを閉じられる
  • ✅ aria-live でスクリーンリーダーに状態変化を通知
  • ✅ aria-busy でロード中状態を通知
  • ✅ アニメーションのみで情報を伝えない（テキストでも補足）
