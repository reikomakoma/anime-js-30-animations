マイクロインタラクションとは

マイクロインタラクション（Micro-interaction）とは、ユーザーの単一の操作に対するシステムの細かなフィードバックのことです。ボタンを押した際の小さなアニメーション、フォーム入力時の即時バリデーション表示、ファイルをドロップした際の受け入れ演出、などが代表例です。

優れたマイクロインタラクションは「気づかれない」が、ないと「なんか使いにくい」と感じさせます。それがUXにおけるマイクロインタラクションの存在意義です。

チェックリスト 12項目

✅ 1. ボタンの押下フィードバック

クリック時に視覚的なフィードバックがあるか。scale縮小（押し込み感）またはopacity低下を使う。

btn.addEventListener('click', () => {
  anime({ targets: btn, scale: [1, 0.95, 1], duration: 200, easing: 'easeOutCubic' });
});

✅ 2. 状態変化の視覚的インジケーター

ON/OFFトグルやお気に入り追加など、状態変化は色+形（またはアイコン）を同時に変化させる。

✅ 3. ローディング状態の表示

非同期処理中は必ずローディングインジケーターを表示。ユーザーを「置いてけぼり」にしない。

// スピナーを表示してAPIコール
const spinner = document.querySelector('.spinner');
anime({ targets: spinner, opacity: [0, 1], duration: 200 });
const anim = anime({ targets: spinner, rotate: '1turn', loop: true, easing: 'linear', duration: 1000 });

fetch('/api/data')
  .then(res => res.json())
  .then(data => {
    anim.pause();
    anime({ targets: spinner, opacity: [1, 0], duration: 200 });
    renderData(data);
  });

✅ 4. 成功フィードバック

フォーム送信成功・操作完了後の肯定的なフィードバック。チェックマークアニメーションや色変化で「完了了」を伝える。

✅ 5. エラーフィードバック

バリデーションエラーは見逃されないよう「シェイク（横揺れ）」または「バウンス（上から落下）」を使う。

function shakeError(el) {
  anime({ targets: el, translateX: [0, -8, 8, -6, 6, -4, 4, 0], duration: 500, easing: 'easeInOutSine' });
}

✅ 6. フォーカス状態の視覚化

フォーカス時にborder-colorやbox-shadowをアニメーションで変化させる。CSSのtransitionで十分なケースが多い。

✅ 7. ホバーフィードバック

インタラクティブな要素はホバー時に変化すること（cursor:pointerだけでは不十分）。translateY:-2px や opacity変化など。

✅ 8. ドラッグ＆ドロップの受け入れ演出

ドロップゾーンに要素が近づいたとき、枠が光る・拡大するなどでドロップ可能を示す。

✅ 9. 削除・破壊操作の確認演出

削除アニメーション（縮小消滅）→ Toastで「削除しました」+「元に戻す」ボタン表示。破壊的操作に対する保険。

✅ 10. インライン編集の遷移

テキストからinputへの切り替え時、高さ変化をアニメーションで滑らかにする。ガタッと変わるのはNGです。

✅ 11. スクロール連動の視覚効果

Intersection Observerでviewport内に入った要素をフェードインさせる（スクロールイベントは使わない）。

✅ 12. Reduced Motion対応

すべての上記インタラクションについて、prefers-reduced-motionがreduceの場合は移動を省き、フェードのみにする。

実装の優先度

12項目すべてを一度に実装しようとするのは禁物です。まずユーザーが最も頻繁に触れる箇所（フォーム・ボタン・ローディング）から始め、段階的に改善していきましょう。マイクロインタラクションの品質はUX全体の品質に直結します。
