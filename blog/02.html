anime.jsとは

anime.js（読み：アニメジェーエス）は、Julian Garnierが開発したオープンソースのJavaScriptアニメーションライブラリです。約17KB（minified+gzip）の軽量さで、CSSプロパティ・DOM属性・SVG・JavaScriptオブジェクトすべてを統一されたAPIでアニメーションできます。MITライセンスのため個人・商用問わず無料で利用できます。

インストール方法

方法1：CDN（すぐ試したい場合）

<!-- HTMLのheadまたはbody末尾に追加 -->
<script src="https://cdnjs.cloudflare.com/ajax/libs/animejs/3.2.1/anime.min.js"></script>

方法2：npm（プロジェクトに組み込む場合）

# npm
npm install animejs

# yarn
yarn add animejs
// ESモジュールとしてインポート
import anime from 'animejs/lib/anime.es.js';

// CommonJSの場合
const anime = require('animejs');

最初のアニメーション

まず最も基本的な例から始めましょう。id="box" の要素を右に200px移動させます。

<!-- HTML -->
<div id="box" style="width:60px;height:60px;background:#6366f1;"></div>

<!-- JavaScript -->
<script>
anime({
  targets: '#box',     // アニメーションする要素（CSSセレクタ or DOM要素）
  translateX: 200,     // 右に200px移動
  duration: 1000,      // 1000ms（1秒）
  easing: 'easeInOutQuad', // イージング
  loop: true,          // 無限ループ
  direction: 'alternate'   // 往復
});
</script>

基本構文の解説

anime()関数は一つのオブジェクトを受け取り、アニメーションオブジェクトを返します。主要なオプションは以下の通りです。

  • targets：アニメーションする要素。CSSセレクタ文字列・DOM要素・NodeList・配列が使えます
  • プロパティ名：translateX, opacity, scale など camelCase で指定
  • duration：ミリ秒（ms）。デフォルト1000ms
  • easing：イージング関数名。デフォルト 'easeOutElastic(1, .5)'
  • delay：アニメーション開始の遅延（ms）
  • loop：true で無限ループ、数値で繰り返し回数
  • direction：'normal' / 'reverse' / 'alternate'

複数プロパティのアニメーション

複数のCSSプロパティを同時に変化させられます。

anime({
  targets: '.card',
  translateY: [30, 0],   // 下から上へ（from値, to値）
  opacity: [0, 1],       // 透明から不透明へ
  scale: [0.95, 1],      // 少し拡大
  duration: 600,
  easing: 'easeOutCubic'
});

Stagger（複数要素への遅延）

複数の要素に対して自動的に計算した遅延を付与します。

anime({
  targets: '.list-item',
  opacity: [0, 1],
  translateX: [-20, 0],
  delay: anime.stagger(100),  // 各要素100ms刻みで遅延
  easing: 'easeOutCubic',
  duration: 400
});

Timeline（複数アニメーションの連携）

複数のアニメーションを順番に・または重ねて実行します。

const tl = anime.timeline({ easing: 'easeOutCubic' });

tl.add({ targets: '#logo', opacity: [0, 1], scale: [0.5, 1], duration: 400 })
  .add({ targets: '#headline', translateY: [20, 0], opacity: [0, 1], duration: 400 }, '-=200') // 200ms前から開始
  .add({ targets: '#cta', scale: [0.9, 1], opacity: [0, 1], duration: 300 }, '-=150');

コールバック

anime({
  targets: '#el',
  translateX: 200,
  duration: 1000,
  begin: (anim) => console.log('アニメーション開始', anim),
  update: (anim) => console.log('progress:', anim.progress + '%'),
  complete: (anim) => console.log('アニメーション完了！')
});
