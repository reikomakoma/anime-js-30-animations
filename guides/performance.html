60fpsとは何か ── なぜ重要か

多くのモニターのリフレッシュレートは60Hz（1秒間に60フレーム）です。アニメーションが60fps（frames per second）で動くと、各フレームの処理に与えられる時間は約16.7msです。この制約内で描画処理を完了できないと「コマ落ち（jank）」が発生し、ユーザーは「カクつき」として認識します。

Chromeの DevTools → Performance パネルで実際のフレームレートを計測できます。60fpsを下回るアニメーションは必ず改善しましょう。

GPUアクセラレーションの活用

ブラウザには描画を担当する「レンダリングパイプライン」があります。CSSプロパティを変更すると、パイプラインの一部または全部が再実行されます。

  • Layout（再描画が重い）：width, height, top, left, margin, padding など
  • Paint（中程度）：background-color, box-shadow, border-color など
  • Composite（最速・GPUのみ）：transform, opacity

アニメーションでは可能な限り transform（translateX/Y, scale, rotate）と opacity のみを使いましょう。これらはGPUで処理されるため、layout/paintをスキップしてcompositeのみで描画されます。

// ❌ leftをアニメーション → layout再計算が毎フレーム走る（重い）
anime({ targets: '#el', left: [0, 100], duration: 500 });

// ✅ translateXをアニメーション → compositeのみ（最速）
anime({ targets: '#el', translateX: [0, 100], duration: 500 });

will-changeプロパティ

will-change はブラウザに「このプロパティが変化する予定」と事前通知し、グラフィック層を事前に確保させます。ただし、すべての要素に設定するのは逆効果です。メモリを多く消費するため、実際にアニメーションする要素にだけ直前で設定し、アニメーション完了後は削除してください。 

// アニメーション開始直前に設定
el.style.willChange = 'transform, opacity';
anime({
  targets: el,
  translateY: [30, 0],
  opacity: [0, 1],
  duration: 600,
  complete: () => {
    el.style.willChange = 'auto'; // 完了後はautoに戻す
  }
});

大量要素のアニメーション

staggerで数百の要素を同時にアニメーションする場合、パフォーマンスが問題になることがあります。

解決策1：requestAnimationFrameとチャンク処理

// 大量要素を50個ずつに分けてアニメーション
const chunks = chunkArray(elements, 50);
chunks.forEach((chunk, i) => {
  setTimeout(() => {
    anime({ targets: chunk, opacity: [0, 1], duration: 400 });
  }, i * 100);
});

解決策2：Intersection Observerで画面外を省略

const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      anime({ targets: entry.target, opacity: [0, 1], translateY: [20, 0] });
      observer.unobserve(entry.target);
    }
  });
}, { threshold: 0.1 });

document.querySelectorAll('.card').forEach(el => observer.observe(el));

ループアニメーションの最適化

loop: true なアニメーションは常にCPU/GPUリソースを消費し続けます。ページがバックグラウンドに入った場合（タブが非表示など）は停止させましょう。

const anim = anime({ targets: '.spinner', rotate: '1turn', loop: true, easing: 'linear' });

// Visibility API でバックグラウンド時は停止
document.addEventListener('visibilitychange', () => {
  if (document.hidden) anim.pause();
  else anim.play();
});

パフォーマンスチェックリスト

  • ✅ translateX/Y / opacity のみでアニメーションしている
  • ✅ width/height/top/left のアニメーションを避けている
  • ✅ アニメーション要素に will-change を適切に設定・解除している
  • ✅ ループアニメーションをバックグラウンド時に停止している
  • ✅ 画面外の要素へのアニメーションを Intersection Observer で制御している
  • ✅ DevTools > Performance でフレームレートを計測している
  • ✅ prefers-reduced-motion でアニメーションを簡略化している
