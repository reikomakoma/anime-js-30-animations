なぜモーション配慮が必要か

世界人口の一定割合が、前庭機能障害（vestibular disorder）や偏頭痛、光過敏症などを持ちます。これらの方々にとって、画面上の激しいモーション（特にパラレックス・大きな平行移動・フラッシュ）は身体的な不快感や、最悪の場合は発作を引き起こすことがあります。

WCAG 2.1 ガイドライン（Success Criterion 2.3.3）では、ユーザーがモーションを止められるようにすることを推奨しています。主要OS（iOS・macOS・Windows・Android）にはシステム設定として「視差効果を減らす / 動きを減らす」オプションが存在します。

prefers-reduced-motion メディアクエリ

CSS/JavaScriptからOS設定を検出できます。

/* CSS */
@media (prefers-reduced-motion: reduce) {
  /* モーションを無効化・最小化 */
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.15s !important;
  }
}
/* JavaScript (anime.jsでの検出) */
const prefersReduced = window.matchMedia('(prefers-reduced-motion: reduce)').matches;

if (prefersReduced) {
  // フェードのみ（移動なし）
  anime({ targets: '.card', opacity: [0, 1], duration: 300 });
} else {
  // フル演出
  anime({ targets: '.card', opacity: [0, 1], translateY: [20, 0], duration: 600 });
}

anime.jsでの実装パターン

パターン1：グローバル設定ユーティリティ

サイト全体でreduced motion設定を一元管理する方法です。

// utils/animation.js
const REDUCED = window.matchMedia('(prefers-reduced-motion: reduce)').matches;

function animeRM(options) {
  if (REDUCED) {
    // 移動をゼロ化、durationを最小化
    const safeOpts = { ...options };
    ['translateX', 'translateY', 'rotate', 'scale'].forEach(k => {
      if (safeOpts[k]) delete safeOpts[k]; // トランスフォームを除去
    });
    safeOpts.duration = Math.min(options.duration || 400, 200);
    return anime(safeOpts);
  }
  return anime(options);
}

// 使用例
animeRM({
  targets: '.hero-text',
  opacity: [0, 1],
  translateY: [30, 0], // reduced time時は除去される
  duration: 700
});

パターン2：staggerの無効化

reduced motion時はスタッガーを0にして즉시表示します。

const REDUCED = window.matchMedia('(prefers-reduced-motion: reduce)').matches;

anime({
  targets: '.nav-item',
  opacity: [0, 1],
  translateX: REDUCED ? 0 : [-16, 0],  // reduced時は移動なし
  delay: REDUCED ? 0 : anime.stagger(80), // reduced時はstagger無効
  duration: REDUCED ? 200 : 400,
  easing: 'easeOutCubic'
});

パターン3：イベントリスナーで動的対応

ページ読み込み後にユーザーが設定を変更した場合にも対応します。

const mq = window.matchMedia('(prefers-reduced-motion: reduce)');

mq.addEventListener('change', (e) => {
  if (e.matches) {
    // すべてのアニメーションを停止
    anime.running.forEach(a => a.pause());
  } else {
    // アニメーションを再開
    anime.running.forEach(a => a.play());
  }
});

何を減らし、何を残すか

「すべてのアニメーションを消す」のはやり過ぎです。適切な判断基準を持ちましょう。

プロパティ Reduced時の対処
translateX/Y（移動） ❌ 停止（0に固定）または大幅縮小
rotate（回転） ❌ 停止（特にループ回転）
scale（拡縮） ⚠️ 小さい変化（0.95→1程度）は許容
opacity（フェード） ✅ OK（durationを短縮推奨）
backgroundColor（色） ✅ OK（transition短縮推奨）

本サイトでの実装

本サイトのHome（30デモ）では、全デモが prefers-reduced-motion: reduce 検出時に自動的に平行移動をゼロ化・スタッガーを最小化してフェード中心の表示に切り替わります。各デモカードの「Reduced Motion」欄で具体的な簡略化内容を確認できます。
