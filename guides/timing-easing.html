イージングとは何か

アニメーションにおける「イージング（easing）」とは、アニメーション開始から終了にかけての速度変化のパターンのことです。現実世界の物体はめったに一定速度で動かず、必ず加速・減速します。このリアルな動きを再現することで、ユーザーは画面上の動きを違和感なく受け入れられます。

anime.jsでは easing プロパティで指定します。デフォルトは 'easeOutElastic(1, .5)' ですが、UIの用途に応じて適切なイージングを選ぶことがプロ品質のアニメーションへの第一歩です。

duration（持続時間）の正しい選び方

durationはミリ秒（ms）で指定します。Googleの「Material Design」ガイドラインでは以下の目安を推奨しています。

  • 100〜200ms：小さな要素のマイクロインタラクション（ボタンのホバー、チェックボックスのオン/オフ）
  • 200〜400ms：モーダルの出現・消滅、ドロップダウンの展開
  • 400〜600ms：ページ遷移、大きなレイアウト変更
  • 600ms以上：ストーリーテリング的な演出（LP ファーストビューのヒーローアニメーション等）に限定

日常的なUIアクション（クリック、スクロール連動等）で600ms以上のアニメーションをつけると「重い・遅い」と感じられます。速いUIは賢く感じさせます。

// ❌ 遅すぎる（日常のUIアクションには不適切）
anime({ targets: '#btn', scale: [1, 1.05], duration: 1200 });

// ✅ 適切（ボタンのホバーフィードバック）
anime({ targets: '#btn', scale: [1, 1.05], duration: 150, easing: 'easeOutCubic' });

主要イージングの種類と使い分け

easeInOut系（最も汎用）

easeInOutQuad、easeInOutCubic、easeInOutSine など。開始と終了が緩やかで中間が速い。ユーザーが移動軌跡を追う場面に最適。カルーセル、プログレスバー、アコーディオンなどのデフォルトとして使える。

easeOut系（入場アニメーションの定番）

easeOutCubic、easeOutExpo、easeOutQuart など。最初が速く、終点でゆっくり止まる。「素早く反応した」という印象を与えつつ、最後は落ち着く。トースト通知・ドロワーの出現などに◎。

easeOutElastic（遊び心・リワード感）

終点でゴムのように伸縮する。SNSの「いいね」ボタン、バッジ獲得エフェクトなどポジティブ感情を強調したいUIに使う。ただし多用するとうるさく感じられる。

// パラメータのチューニング
// easeOutElastic(amplitude, period)
// amplitude(振幅): 1〜3、period(周期): 0.3〜0.6
anime({ targets: '#heart', scale: [0, 1], easing: 'easeOutElastic(1, 0.5)', duration: 700 });

spring()（物理ベース・最高品質）

4つの物理パラメータ（mass・stiffness・damping・velocity）でバネの挙動を計算。durationが自動決定されるため、どんな距離でも一定の「ネイティブアプリ的な質感」を保てる。トグルスイッチ、スライダーなどに。 

// spring(mass, stiffness, damping, velocity)
anime({ targets: '#thumb', left: [0, 24], easing: 'spring(1, 120, 10, 0)' });

easeOutBounce（重力感・注意喚起）

ボールが床に弾むような一方向の反発。フォームのバリデーションエラー通知、警告トーストなど「見逃してはいけないお知らせ」に。

delay（遅延）とstaggerの設計

複数の要素が同時に動くと「重たい」「賑やかすぎる」という印象を与えます。delayでズレをつけることで視線の流れを美しくコントロールできます。

// anime.stagger: 要素ごとに自動計算した遅延を付与
anime({
  targets: '.card',
  opacity: [0, 1],
  translateY: [20, 0],
  delay: anime.stagger(80),           // 各要素80ms刻み
  // delay: anime.stagger(80, { from: 'center' })  // 中心から外側へ波状
  easing: 'easeOutCubic',
  duration: 500
});
