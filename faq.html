よくある質問

anime.jsとこのサイトについてよく寄せられる質問をまとめました

anime.js基本

  • anime.jsは無料で使えますか？ +
    はい、anime.jsはMITライセンスで公開されているオープンソースのJavaScriptライブラリです。個人利用・商用利用を問わず、完全無料でご利用いただけます。npm（npm install animejs）やCDN経由で簡単に導入できます。
  • anime.jsのバージョン3.xと4.xは何が違いますか？ +
    本サイトはanime.js 3.x系を対象としています。3.xは現在最も広く使われており、安定したAPIを提供しています。4.xは開発中のメジャーアップデートで、より型安全なAPIが予定されていますが、3.xとの互換性はないため移行が必要になります。本サイトのコードは3.x向けです。
  • anime.jsはReact / Vue / Svelteで使えますか？ +
    はい、anime.jsはフレームワーク非依存のライブラリです。ReactではuseEffect + useRef、VueではonMounted + templateRef、SvelteではonMount + bind:thisを使ってDOM参照を取得し、anime()に渡すことで利用できます。ただし、DOMをanime.jsが直接操作するため、Reactの仮想DOMとの競合に注意が必要です。コンポーネントのアンマウント時にアニメーションを停止・クリーンアップすることを忘れずに。
  • CSSアニメーションやGSAPと比べた場合のanime.jsのメリットは？ +
    CSS Transitionと比べたメリット：複数プロパティの連携・タイムライン管理・コールバック・SVGアニメーションがJavaScriptで一元管理できます。
    GSAPと比べたメリット：ファイルサイズが小さく（約17KB min+gzip）、シンプルなAPIで学習コストが低いです。また完全無料で商用利用できます（GSAPは一部機能が有料）。
    プロジェクトの規模が大きい場合や高度な機能（ScrollTrigger等）が必要な場合はGSAPが優位ですが、個人・中小規模のプロジェクトではanime.jsが最適解になることが多いです。
  • モバイル・スマートフォンでも正常に動作しますか？ +
    はい、anime.jsはiOS Safari・Android Chromeを含む主要なモバイルブラウザで動作します。本サイトのデモもモバイルで閲覧可能です。ただし、低スペックなデバイスでは複雑なアニメーション（特に多数の要素・長いスタッガー）が重くなる場合があります。パフォーマンス最適化ガイドも参考にしてください。

実装・コード

  • アニメーションが動かない場合のチェックリストは？ +
    まず以下を確認してください。① anime.jsが正しく読み込まれているか（typeof anime !== 'undefined'をコンソールで確認）、② ターゲットのセレクタが正しいか（document.querySelector(targets)でnullでないか）、③ アニメーションするプロパティ名が正しいか（camelCaseで指定）、④ durationが設定されているか（デフォルト1000ms）、⑤ console.log(anime({...}))でアニメーションオブジェクトが返されているか。詳しくはよくあるミスガイドを参照してください。
  • prefers-reduced-motionへの対応はどうすればよいですか？ +
    window.matchMedia('(prefers-reduced-motion: reduce)').matchesでユーザーの設定を確認できます。trueの場合は、移動（translateX/Y）をゼロにし、フェード（opacity）のみに簡略化するのが推奨です。スタッガーも最小化または無効化してください。詳しくはモーション配慮設計ガイドをご覧ください。
  • 複数のアニメーションを順番に実行するにはどうすればいいですか？ +
    anime.timeline()を使うのが最もスマートな方法です。.add()でアニメーションを追加し、オフセット（'-=300'）で重ね合わせも制御できます。単純なシーケンスであればcompleteコールバックで次のアニメーションを呼び出す方法も使えます。デモ #17（タイムライン制御）で実例を確認できます。
